Claws Press-On Nails Website
Project Description
Claws is a South African small business website created for a press-on nail business. The website allows customers to explore different nail designs, learn more about the business, view a sizing guide, place custom orders, and find contact information.
The website uses HTML and CSS to create a stylish, simple, and user-friendly design.
The main design colours are soft pink, white, and gold, giving the website a feminine, elegant, and modern appearance.




Technologies Used
•	HTML5
•	CSS3
•	Google Fonts
•	Images
•	Responsive CSS



CSS Features
The styles.css file is used to control the appearance of the different pages on the Claws website.
1. Website Base Style
The CSS sets the main font, font size, line spacing, text colour, background colour, and background image for the website.

2. Headings
The website uses Playfair Display SC for headings. This gives the website a more elegant and luxurious appearance.
The main heading uses a gold colour to match the Claws branding.


4. Images
Images are have  rounded corners to make the website look softer and more modern.
The image styling also allows images to adjust to different screen sizes.


6. Shop Button
The  shop button class creates the Shop Now button.
The button has:
•	Pink background
•	White text
•	Rounded corners
•	Bold text
•	Hover effect
When the user moves their mouse over the button, the colour changes.


8. Forms
CSS is also used to style the custom order form.
The form includes:
•	Text fields
•	Dropdown menus
•	Text areas
•	Buttons
•	Labels
This makes the custom order page easier to read and use.



10. Footer
The footer uses the same soft pink colour scheme as the navigation bar to keep the design consistent throughout the website.


12. Responsive Design
A media query was added so the website can work better on smaller screens such as tablets and mobile phones.
The layout changes when the screen becomes smaller, making the website easier to use on different devices.

Website Pages
The Claws website contains several pages:
1.	Home Page – Introduces the Claws business and showcases nail designs.
2.	About Us – Explains the story behind Claws and introduces the owner.
3.	Shop – Displays the available press-on nail designs and prices.
4.	Custom Orders – Allows customers to provide their nail preferences and design ideas.
5.	Contact Us – Provides ways for customers to contact Claws.
6.	Sizing Guide – Helps customers choose the correct nail size.



Design Choices
The colour scheme was chosen to represent the Claws brand.
•	Soft Pink – Gives the website a soft and feminine appearance.
•	White – Keeps the website clean and simple.
•	Gold – Adds an elegant and premium feeling.
•	Dark Text – Makes the information easy to read.
The rounded buttons, images, and sections help create a consistent design across the website.


Challenges Experienced
1. Fixing CSS Comments
One challenge was learning that CSS comments must use:
/* Comment */
instead of HTML comments:
<!-- Comment -->
Using the wrong comment format can cause problems with the CSS code.
2. Keeping the Design Consistent
It was challenging to make sure that all the website pages had the same colours, fonts, navigation, buttons, and overall appearance.
Using one shared styles.css file helped solve this problem.
3. Making the Website Responsive
Another challenge was making the website work on different screen sizes.
The layout needed to change when viewed on a smaller device. Media queries were used to make the website more mobile-friendly.
